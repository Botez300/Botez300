# Agency Agents skills

283 specialist skills (engineering, design, marketing, sales, security, finance, game dev, and more), converted from [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) at commit `b37b5bb` using its own `scripts/convert.sh --tool dsh` (standard Agent Skills SKILL.md format).

Use one by name (e.g. `/agency-frontend-developer`) or just describe the task and Claude picks the matching skill.

To update: clone the upstream repo, run `./scripts/convert.sh --tool dsh --out /tmp/out`, and copy `/tmp/out/dsh/*` here.
